Resumo

Sou estudante de Desenvolvimento de Software pela FATEC, cursando o 4º semestre, e atuo como bolsista de Iniciação Científica.

Tenho ampla experiência no desenvolvimento de software para produtos tecnológicos e pesquisa científica, com paixão por aprender novas tecnologias e aplicar conhecimentos no mundo real, transformando e solucionando problemas. Sou fascinado por psicologia, agropecuária e computação, onde combino meus conhecimentos para otimizar soluções complexas a partir de ideias simples.

Minha trajetória é guiada pelo propósito de aliar desenvolvimento e inovação a um ambiente acolhedor, gerando soluções inovadoras que transformam vidas.

Primeiro Semestre

Projeto: Plataforma Educacional sobre Metodologia Ágil SCRUM

Este foi meu primeiro projeto como Scrum Master, aplicando conhecimentos em gerenciamento de projetos.
O desafio consistiu no desenvolvimento de uma aplicação web interativa para ensinar os fundamentos da metodologia ágil SCRUM.

A plataforma oferece conteúdo teórico e atividades práticas, com emissão de certificado personalizado.

Tecnologias utilizadas: JavaScript, HTML, CSS, GitHub, GitHub Pages.

Segundo Semestre

Projeto: Sistema Web para Manipulação de Projetos de Mapeamento

Desenvolvido como Desenvolvedor de Software na FATEC, o projeto criou uma aplicação web para gerenciamento de projetos de mapeamento.
O sistema oferece funcionalidades para registrar, editar e visualizar projetos de forma estruturada.

Tecnologias utilizadas: TypeScript, PostgreSQL com PostGIS, HTML.

Terceiro Semestre

Projeto: Aplicativo de Monitoramento Nutricional

Desenvolvido como Desenvolvedor de Software na FATEC, o aplicativo monitora a ingestão diária de calorias e nutrientes.
Combina funcionalidades práticas com uma interface intuitiva para acompanhamento da dieta.

Tecnologias utilizadas: Node.js, TS-Node.js, MongoDB, TypeScript, React, Trello, Kanban.

Quarto Semestre

Projeto: Aplicativo de Monitoramento via Dispositivo IoT

Desenvolvido como Desenvolvedor de Software na FATEC, o aplicativo monitora dados coletados por um dispositivo IoT.
Integra hardware e software para monitoramento em tempo real.

Tecnologias utilizadas: Node.js, TS-Node.js, MongoDB, TypeScript, React, React Native, Android, iOS, C++, Trello, Kanban.
