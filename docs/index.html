Primeiro Semestre

Projeto: Plataforma Educacional sobre Metodologia Ágil SCRUM

Como integrante do time de desenvolvimento, participei ativamente da criação de uma aplicação web interativa, aplicando minhas habilidades em programação para construir uma ferramenta educacional voltada ao ensino dos fundamentos da metodologia ágil SCRUM. O projeto uniu teoria e prática, oferecendo conteúdo dinâmico, atividades interativas e certificados personalizados para os usuários.

Colaborei na codificação, na coleta de dados oficiais para enriquecer o curso e na validação do conteúdo, garantindo precisão, funcionalidade e uma experiência de aprendizado de alta qualidade. Meu trabalho foi essencial para a entrega de uma solução robusta e acessível.

Tecnologias utilizadas: JavaScript, HTML, CSS, GitHub, GitHub Pages.

Segundo Semestre

Projeto: Sistema Web para Gerenciamento de Projetos de Mapeamento com Georreferenciamento

Como Desenvolvedor de Software na FATEC, contribuí para o desenvolvimento de uma aplicação web voltada ao gerenciamento eficiente de projetos de mapeamento, com foco em dados de georreferenciamento. O sistema foi projetado para registrar, editar e visualizar projetos de forma estruturada, integrando informações espaciais em um banco de dados robusto para suportar análises e consultas avançadas.

Minha atuação envolveu a implementação de funcionalidades no front-end e a integração com o banco de dados geoespacial, garantindo precisão e desempenho na manipulação de dados de localização. O projeto resultou em uma solução prática para organização e visualização de informações geográficas.

Tecnologias utilizadas: TypeScript, PostgreSQL com PostGIS, HTML.

Terceiro Semestre

Projeto: Aplicativo Fitness de Monitoramento Nutricional

Como Desenvolvedor de Software na FATEC, contribuí para o desenvolvimento de um aplicativo Fitness inovador, projetado para monitorar e gerenciar a ingestão diária de calorias, nutrientes e dietas personalizadas. A solução utiliza um banco de dados não relacional MongoDB para armazenar dados flexíveis e escaláveis, permitindo o rastreamento detalhado de hábitos alimentares e objetivos de saúde de forma eficiente.

Minha atuação incluiu a criação de funcionalidades no front-end com React, a integração com o back-end em Node.js e TS-Node.js, e a modelagem de dados no MongoDB para suportar análises personalizadas de calorias e nutrientes. O resultado foi uma interface intuitiva e prática, que empodera os usuários a otimizar suas dietas com base em dados em tempo real, apoiada por uma gestão ágil com Trello e Kanban.

Tecnologias utilizadas: Node.js, TS-Node.js, MongoDB, TypeScript, React, Trello, Kanban.

Quarto Semestre

Projeto: Aplicativo de Monitoramento em Tempo Real com Dispositivo IoT

Como Desenvolvedor de Software na FATEC, liderei o desenvolvimento de um aplicativo multiplataforma para monitoramento em tempo real de dados coletados por dispositivos IoT embarcados. O sistema integra hardware e software, utilizando sensores programados em C++ para coletar e processar dados ambientais, que são transmitidos para uma aplicação mobile desenvolvida em React Native, compatível com Android e iOS.

Minha atuação envolveu a programação de firmware em C++ para microcontroladores, garantindo eficiência e baixo consumo de energia, além da implementação de uma API robusta em Node.js e TS-Node.js para comunicação segura entre dispositivos IoT e o banco de dados MongoDB. No front-end, desenvolvi interfaces interativas em React e React Native, permitindo aos usuários visualizar dados em tempo real e configurar alertas personalizados. A gestão do projeto foi conduzida com metodologias ágeis, utilizando Trello e Kanban para organização e colaboração em equipe.

O resultado foi uma solução escalável e confiável, que combina software embarcado e tecnologias modernas para oferecer monitoramento contínuo e insights acionáveis, com aplicações potenciais em automação residencial, agricultura de precisão e monitoramento ambiental.

Tecnologias utilizadas: C++, Node.js, TS-Node.js, MongoDB, TypeScript, React, React Native, Android, iOS, Trello, Kanban.
